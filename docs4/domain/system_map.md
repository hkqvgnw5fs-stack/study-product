# Карта системы

## Роли
- **Пользователь** — создаёт и просматривает свои заявки, оставляет комментарии
- **Администратор** — видит все заявки, меняет статусы

## Сущности
- **Пользователь** (id, имя, почта, роль)
- **Заявка** (id, тема, описание, статус, дата, автор)
- **Комментарий** (id, текст, дата, автор, заявка)

## Основные сценарии

1. **Создание заявки** — пользователь заполняет тему и описание, система создаёт заявку со статусом "новая"
2. **Просмотр списка** — пользователь видит все свои заявки с темой и статусом
3. **Просмотр карточки** — пользователь открывает заявку, видит детали и комментарии
4. **Изменение статуса** — администратор меняет статус заявки на "в работе" или "закрыта"
5. **Добавление комментария** — пользователь пишет комментарий к своей заявке

## Интерфейс (экраны)

| Экран | Описание | User Stories |
|-------|----------|--------------|
| Список заявок | Таблица со всеми заявками пользователя, кнопка "Создать" | US-03 |
| Создание заявки | Форма с полями "Тема" и "Описание", кнопка "Создать" | US-02 |
| Карточка заявки | Детали заявки, статус, комментарии, кнопка "Добавить комментарий" | US-04, US-07 |
| Все заявки (админ) | Список всех заявок всех пользователей | US-06 |
| Статистика | Количество заявок по статусам | US-09 |

## API (эндпоинты)

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | /tickets | Создать заявку |
| GET | /tickets | Список заявок |
| GET | /tickets/{id} | Карточка заявки |
| PATCH | /tickets/{id} | Изменить статус |
| POST | /tickets/{id}/comments | Добавить комментарий |
| GET | /tickets/{id}/comments | Список комментариев |
