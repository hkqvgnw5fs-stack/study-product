# Журнал изменений

Все значимые изменения по проекту фиксируются в этом файле.

---

## [1.0.0] - 2026-04-15

### Добавлено
- Реализовано создание задач с проверкой названия
- Реализован просмотр списка всех задач
- Добавлена команда изменения статуса задачи
- Добавлен поиск задач по ключевому слову
- Реализовано сохранение задач в JSON-файл
- Реализована загрузка задач из JSON-файла при запуске
- Добавлена обработка ошибок ввода (пустое название, буквы вместо числа)

### Изменено
- Обновлён формат отображения статуса задачи
- Улучшена структура сообщений об ошибках

### Исправлено
- Исправлено падение программы при пустом названии задачи
- Исправлена ошибка загрузки при отсутствии файла данных
- Исправлено падение при вводе букв вместо числа
- Исправлена ошибка при eps=0 в калькуляторе

### Известные ограничения
- Поиск работает только по названию, описание не учитывается
- Приложение тестировалось только на Windows 10 и Python 3.11
- Импорт задач из старого формата JSON не поддерживается
- Одновременная работа нескольких пользователей не предусмотрена
