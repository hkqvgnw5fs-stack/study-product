# Модель предметной области

## Сущности и атрибуты

### Пользователь (User)
- id — уникальный идентификатор
- name — имя пользователя
- email — электронная почта
- role — роль (пользователь / администратор)

### Заявка (Ticket)
- id — уникальный идентификатор
- title — тема заявки
- description — описание
- status — статус (новая, в работе, закрыта)
- created_at — дата создания
- author_id — ссылка на пользователя (кто создал)

### Комментарий (Comment)
- id — уникальный идентификатор
- text — текст комментария
- created_at — дата создания
- author_id — ссылка на пользователя (кто написал)
- ticket_id — ссылка на заявку

### Статус (Status)
- значения: новая, в работе, закрыта

## Связи между сущностями

- Пользователь 1 --- N Заявка (один пользователь создаёт много заявок)
- Заявка 1 --- N Комментарий (у одной заявки много комментариев)
- Пользователь 1 --- N Комментарий (один пользователь пишет много комментариев)
